## 🧠 About me

```txt
I create digital products where clean code meets thoughtful design.
```

Привет! Я **Кирилл Волков** — разработчик, преподаватель IT/AI и автор образовательных и продуктовых проектов.  
Мне близки **frontend-разработка**, **Flutter-приложения**, **AI-инструменты**, красивые интерфейсы и практичные системы, которые реально помогают людям.

Сейчас я развиваю несколько направлений:

- 🚀 **VolkoWeb** — личный бренд / IT-студия разработки
- ✅ **QDone** — современное To-Do приложение на Flutter
- 📊 **Kvanteval** — система оценивания проектов
- 🎨 **Артист** — сайт и цифровая экосистема для творческого коворкинга
- 🧑‍🏫 **IT & AI Education** — материалы, курсы и практические занятия для школьников
